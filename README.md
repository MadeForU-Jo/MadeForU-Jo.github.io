# MadeForU — متجر الهدايا والمصنوعات المخصصة

الموقع الإلكتروني الرسمي لمتجر **MadeForU** في الأردن 🇯🇴.
متخصصون في الهدايا والمصنوعات اليدوية والهندسية المخصصة من خشب MDF الصلب والأكريليك الفاخر مقاس 40 سم، مع إمكانية الحفر المخصص بالليزر للأسماء والتواريخ وعبارات الإهداء.

## المميزات
- خامات صلبة فاخرة (خشب MDF صلب وأكريليك عصري)
- حفر ليزر مخصص للإهداءات والأسماء
- تجربة شراء سريعة ومباشرة عبر الواتساب
- الدفع عند الاستلام (كاش) في كافة محافظات المملكة
- أجرة توصيل ديناميكية (عمان 1 د.أ / باقي المحافظات 2 د.أ)
