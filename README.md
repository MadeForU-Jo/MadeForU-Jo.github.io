# 🧩 متجر PuzzleMe JO — بازل وأحاجي خشبية (عمان، الأردن)

موقع ويب عربي متكامل وخفيف لعرض وبيع ألعاب البازل والأحاجي الخشبية في عمان والأردن بنظام **الدفع عند الاستلام (كاش)** مع احتساب أجرة توصيل ثابتة (1 دينار).

---

## 🚀 تجربة الموقع على جهازك
افتح المجلد `f:\PuzzlemeWebsite` واضغط مرتين على الملف **`index.html`** ليعمل الموقع فوراً في متصفحك.

---

## 📸 إضافة صورك الخاصة ومنتجاتك الجديدة

لقد أنشأنا لك مجلداً جاهزاً للصور باسم: `images/`.

### 1. كيف تضيف صور البازل من جهازك؟
1. انسخ صور البازل وضعها داخل المجلد: `f:\PuzzlemeWebsite\images\` (مثال: `puzzle1.jpg`, `puzzle2.png`).
2. افتح ملف `products.js` وفي خانة `image` اكتب المسار هكذا:
   ```javascript
   image: "images/puzzle1.jpg"
   ```

### 2. كيف تضيف منتجاً جديداً أو تعدل الأسعار؟
افتح ملف **`products.js`** وستجد قائمة المنتجات مرتبة هكذا:
```javascript
{
  id: 7,
  title: "اسم البازل الجديد",
  category: "بازل خشبي فني",
  price: 10,                 // السعر بالدينار الأردني
  pieces: "150 قطعة",        // عدد القطع
  dimensions: "25 × 25 سم",  // المقاس
  badge: "جديد",             // شارة اختيارية
  shortDesc: "وصف مختصر يظهر في البطاقة الرئيسية...",
  description: "وصف كامل وتفصيلي يظهر عند الضغط على المنتج...",
  image: "images/puzzle7.jpg"
}
```

### 3. إعدادات المتجر ورقم الواتساب:
في بداية ملف `products.js`:
```javascript
const STORE_CONFIG = {
  storeName: "PuzzleMe JO",
  currency: "د.أ",          // دينار أردني
  deliveryFee: 1.0,         // أجرة التوصيل ثابتة: 1 دينار
  city: "عمان، الأردن",
  whatsappNumber: "962790000000" // رقم هاتفك بدون + أو مسافات (مثال: 962791234567)
};
```

```bash
git push origin main
```
